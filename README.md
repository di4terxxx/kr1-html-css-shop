# Учебный интернет-магазин

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема: многостраничный сайт интернет-магазина.

## Структура проекта
- `index.html` — главная страница (hero, преимущества, популярные товары)
- `catalog.html` — каталог товаров с фильтрами
- `product.html` — карточка товара с таблицей характеристик
- `order.html` — форма оформления заявки
- `contacts.html` — контактная информация и форма обратной связи
- `css/style.css` — файл стилей с CSS-переменными и БЭМ
- `js/main.js` — логика модального окна
- `images/` — папка для изображений
- `.gitignore` — список файлов, исключённых из Git
- `README.md` — описание проекта

## Используемые технологии
- HTML5 (семантическая разметка)
- CSS3 (переменные, Flexbox, Grid, позиционирование)
- БЭМ-именование классов
- JavaScript (минимальная логика модального окна)
- Git, GitHub, GitHub Pages

## Реализованные требования
- 5 связанных страниц с единой навигацией
- Семантические теги: header, nav, main, section, article, aside, footer
- Якорные ссылки (#advantages, #popular)
- Карточки товаров с бейджами (Хит, Скидка, Новинка)
- Таблица характеристик товара
- Форма заявки и форма обратной связи
- Модальное окно через `<dialog>`
- CSS-переменные в `:root`
- Состояния `:hover` и `:focus-visible`
- Flexbox (навигация) и CSS Grid (каталог, контакты)
- БЭМ-именование классов
- Позиционирование: sticky (шапка), fixed (кнопка наверх), absolute (бейджи), relative (карточки)
- Хлебные крошки на странице товара

## Самостоятельные доработки
- Добавлена кнопка "Наверх" (fixed позиционирование)
- Хлебные крошки на странице товара
- Бейджи товаров с разными модификаторами (Хит/Скидка/Новинка)
- Двухколоночная сетка на странице контактов
- Улучшенная доступность: aria-label, focus-visible, aria-invalid
